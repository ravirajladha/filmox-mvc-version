# Filmox - Social Networking Website for Film Industry (PHP MVC Version)

Filmox is a social networking platform built with PHP MVC, designed for the film industry. It connects actors, actresses, and other professionals, enabling them to create profiles, network, share media, and collaborate on projects. This repository contains the PHP MVC version of Filmox, with an updated Laravel version planned for a future release.

## Features

- **Profile Creation**: Actors and actresses can create detailed profiles with bios, photos, and filmography.
- **Networking**: Connect with other film industry professionals, follow users, and send messages.
- **Media Sharing**: Upload photos, videos, and portfolio items to showcase work.
- **Project Collaboration**: Post casting calls, collaborate on projects, and discover opportunities.
- **MVC Architecture**: Organized codebase using the Model-View-Controller pattern for scalability.

## Prerequisites

- PHP >= 7.4
- MySQL or MariaDB
- Apache (e.g., via XAMPP)
- Composer for dependency management
- Git
